# Idiomas: português e inglês

Decidido em 11/09/2026. Português na raiz (`modelseason.com`), inglês em `/en`. Nenhuma URL publicada muda, a série do GA continua e o SEO atual fica intacto. O inglês só vai ao ar completo: nada é publicado pela metade.

## Arquitetura

| Peça | Onde | Regra |
|---|---|---|
| Idiomas e rotas | `lib/i18n.ts` | `IDIOMAS = ['pt', 'en']`. `Texto<V> = Record<Lang, V>`: acrescentar um idioma faz o TypeScript apontar cada texto sem versão |
| Rota | `app/[lang]/...` | Um root layout só, com `lang` vindo da URL. `next.config.ts` reescreve tudo que não começa com `/en` para `/pt/...` sem mudar a URL, e `/pt/...` redireciona 308 para a raiz |
| Formatação | `lib/format.ts` | `formatadores(lang)`. Português idêntico à v1, travado por `tests/format.test.ts` contra `tests/fixtures/format-pt.json` |
| Rótulos do dado | `lib/rotulos.ts` | Chave do dado nunca muda (`'EUA/Canadá'`, `'Outros'`, `'Até $0,20'`): ela dá cor, ordem, filtro e aparece na URL de um recorte. Só o rótulo exibido é traduzido. O teste falha se o `data.json` trouxer um valor sem rótulo em inglês |
| Texto de interface | no próprio componente | `t({ pt: '...', en: '...' })`, as duas versões lado a lado, para revisar e para não divergir |
| Texto editorial | `content/graficos/{pt,en}`, `content/indicadores/{pt,en}` | Mesmo nome de arquivo nos dois idiomas. `scripts/conteudo.mjs` exige paridade (mesmos gráficos, mesmo tipo, mesmos indicadores) e recusa marca de português no inglês. Em CI e na Vercel é estrito; localmente, arquivo que falta cai no português com aviso |
| Texto gerado por regra | `data/web` emite números e chaves; o texto é montado no front, por idioma | O pipeline não escreve frase. Número formatado em Python ("10,1%") não entra no inglês |
| Componente cliente | `useIdioma()` de `components/shell/Idioma.tsx` | Devolve `{ lang, f, t, url, modelo, lab, valor, ... }` |
| Componente de servidor | `idioma(lang)` de `lib/idioma.ts` | O mesmo objeto, sem hook |

## Convenções de formato

| | Português | Inglês |
|---|---|---|
| Decimal | `12,3%` | `12.3%` |
| Pontos percentuais | `+5,5 pp` | `+5.5 pp` |
| Dólar | `US$ 3,00` | `$3.00` |
| Milhões de dólares | `US$ 1,2 mi` | `$1.2M` |
| Contagem | `16,0 mi`, `820 mil` | `16.0M`, `820K` |
| Tokens | `1,3T` | `1.3T` |
| Data curta | `08 set 26` | `Sep 8, 2026` |
| Mês | `set 26` | `Sep 2026` |
| Data completa | `08/09/2026` | `Sep 8, 2026` (data numérica nunca, 08/09 é ambígua) |
| Eixo | `08 set`, `set 26` | `Sep 8`, `Sep '26` |
| Ordinal | `15º` | `15th` |
| Lista | `a, b e c` | `a, b and c` (sem vírgula de Oxford) |

Pendência conhecida, igual nos dois idiomas: número acima de mil sai sem separador de milhar (`US$ 1235 mi`). Corrigir muda o português, então fica para uma decisão à parte.

## Estilo do inglês

Inglês americano. Registro de mesa de dados, não de marketing: frase declarativa, número antes de adjetivo, nada de "revolutionary", "game-changer" ou exclamação. Caixa de frase em título e rótulo ("Share by lab", não "Share By Lab"). Sem travessão (a mesma regra do português). Nome de modelo, de laboratório, de avaliação e de índice da Artificial Analysis não se traduz. "OpenRouter" continua só na atribuição do rodapé.
